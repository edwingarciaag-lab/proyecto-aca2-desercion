# Predicción de Deserción Universitaria con Deep Learning (ACA N° 2)

Aplicación web interactiva desarrollada en Streamlit que integra una base de datos SQLite y una Red Neuronal Artificial (MLP) para predecir la deserción estudiantil.

## Cómo ejecutar el proyecto localmente
1. Clonar o descargar este repositorio.
2. Instalar las librerías necesarias:
   pip install -r requirements.txt
3. Ejecutar la aplicación:
   streamlit run app.py
